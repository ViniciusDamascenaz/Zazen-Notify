# Zazen

> **Esse momento nunca mais vai existir.**

Zazen is a minimalist Android application designed to create small moments of presence throughout the day.

In a world constantly competing for our attention through notifications, messages, social media and endless information, Zazen takes a different approach: instead of asking you to disconnect from the world, it simply reminds you to **notice the moment you're already in**.

## Concept

Zazen was built around a simple idea:

**You don't need to stop your life. You just need to notice it.**

The application periodically delivers short prompts designed to bring attention back to the present moment through breathing, touch, sounds, body sensations and the surrounding environment.

These aren't traditional motivational quotes.

They are small invitations to observe.

## Features

* Minimalist interface
* Customizable notification schedule
* Randomized mindfulness prompts
* Non-repeating prompts
* Sensory and breathing exercises
* Lightweight Android application
* Designed to work quietly in the background

## Development

Zazen is an Android project developed in Java.

The project was created as both a software project and an exploration of how technology can be used to encourage presence rather than constant consumption.

## Status

Zazen is currently in its final development and refinement stage.

**Official launch: October 20, 2026.**

A beta version is also available for testing before the official release.

## Philosophy

Technology is not necessarily the problem.

The problem is when we stop noticing how much of our attention it consumes.

Zazen is an experiment in using technology to give a small part of that attention back.
